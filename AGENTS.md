# AGENTS

This repository is jointly developed by Codex and Kimi.

## Mandatory Rules

- Every agent must read `AGENTS.md`, `HANDOFF_STATE.md`, `NEXT_TASK.md`, and `SYSTEM_ARCHITECTURE.md` before making changes.
- Nothing is considered complete until the relevant tests pass.
- Do not duplicate code or create parallel logic without a clear reason.
- Take a backup at every clean milestone before major structural changes.
- Keep handoffs short, explicit, and actionable.
- Preserve deterministic behavior in decision logic and keep execution isolated by default.
